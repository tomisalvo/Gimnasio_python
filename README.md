# Gimnasio_python
Proyecto final para diplomatura en Python
Se realizo una app para ingreso y gestion de clientes de un gimnasio.
A travez de ella se puede realizar Alta, baja, modificacion y consulta de clientes.
Tambien tiene la utilidad de funcionar como app de ingreso, permitiendo o no el acceso a los abonados.
Y por ultimo podemos obtener un listado completo de nuestros clientes.
